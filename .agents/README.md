# Agent assets

This directory contains canonical workflows and implementation coordination assets.

- `skills/`: reusable workflows for product operation and repository development.
- `plan/`: implementation plans and design artifacts.
- `templates/`: work-order and report templates.
- `work-orders/`: assignments created and reviewed by the implementation lead.

Agent-specific directories such as `.claude/skills/` are generated adapters. Do not make them the source of truth.
