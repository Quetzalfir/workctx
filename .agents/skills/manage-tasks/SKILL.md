# Manage tasks

## Procedure

1. Resolve the focal task or initiative and retrieve its context pack.
2. Confirm whether the work belongs to an existing parent workstream.
3. Create a new parent only for a distinct objective with its own deliverable or ownership.
4. Create a subtask only for a real independently trackable slice.
5. Represent current status, owner, requester, deadline, and waiting-on through validated fields/claims and preserve history.
6. Add typed dependencies and blockers; check for cycles.
7. Attach source observations supporting every material state change.
8. Record the next best action and minimum unblock action.
9. Create contextual draft messages when another person must respond.
10. Apply changes transactionally and regenerate operational views.

## Response structure to the human operator

- current state;
- completed work;
- blockers and missing information;
- dependencies and people awaited;
- next best action;
- suggested message when useful;
- exact evidence references for material claims.
