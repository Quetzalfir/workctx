# Acceptance criteria

## Functional

- [ ] Replace with observable behavior.

## Negative and edge cases

- [ ] Replace with expected failure behavior.

## Quality

- [ ] Tests added or updated.
- [ ] Documentation matches behavior.
- [ ] Allowed paths only.
- [ ] No secrets or private data.
