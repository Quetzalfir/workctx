# Work Context workspace

This directory is an isolated source of truth for one company, product, project, personal,
or laboratory boundary.

Open the directory in a supported AI agent after installing the project adapter. The agent must use canonical context and `workctx` tools instead of relying on chat history.

## File placement

Before creating or modifying a file whose placement or ownership is uncertain, run `workctx guide`; generated files are never hand-edited.

Do not store secret values in this workspace.
